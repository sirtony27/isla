# 0003 — v0.2: avisos del sistema y opciones

Estado: aprobada por el dueño (2026-10-26).
Complementa: 0001, 0002. Presupuesto: `AGENTS.md`.

## Funciones y mecanismo (todas por evento, ninguna consulta periódica)

| Función | Fuente del evento | Hilo |
|---|---|---|
| Volumen (aviso + fila en el panel + rueda del mouse) | `IAudioEndpointVolumeCallback` (Core Audio) | callback de Windows → `PostMessage` |
| Salida de audio cambiada | `IMMNotificationClient::OnDefaultDeviceChanged` (render, consola) | callback → `PostMessage` |
| Brillo (pantalla interna) | `RegisterPowerSettingNotification(GUID_VIDEO_CURRENT_MONITOR_BRIGHTNESS)` | UI |
| Batería baja (20 %, 10 %) y carga completa | `GUID_BATTERY_PERCENTAGE_REMAINING` + `PBT_APMPOWERSTATUSCHANGE` | UI |
| Micrófono / cámara en uso | `RegNotifyChangeKeyValue` sobre `CapabilityAccessManager\ConsentStore` | hilo propio bloqueado en `WaitForMultipleObjects` |
| Pomodoro | timer al próximo cambio de minuto (cerrado) o 1 Hz (panel abierto) | UI |
| Atajo Win+Alt+N | `RegisterHotKey` (no es un hook de teclado) | UI |
| Monitor con la ventana activa | `SetWinEventHook(EVENT_SYSTEM_FOREGROUND, WINEVENT_OUTOFCONTEXT)`, solo si está elegido | UI |
| Modo solo avisos | sin píldora; una franja invisible de 4 DIP arriba abre el panel | — |

Notas:
- `SetWinEventHook` es un evento de accesibilidad fuera de proceso, no un hook de teclado o mouse.
  Se instala solo con la opción "monitor con la ventana activa".
- Las notificaciones de energía envían el valor actual al registrarse: el primer valor no genera aviso.
- Mic/cámara: una app usa el dispositivo si su clave tiene `LastUsedTimeStart > 0` y
  `LastUsedTimeStop == 0` (claves empaquetadas y `NonPackaged`).

## Panel abierto (420 × 212 DIP)

1. Música (igual que v0.1) · 2. Progreso · 3. **Volumen**: icono (clic = silenciar), barra
(clic/arrastrar), porcentaje · 4. Tres tarjetas: **Agua** (clic = +vaso) · **Pomodoro**
(clic = iniciar/detener) · **Batería** (o fecha en escritorio).

## Ajustes nuevos (`settings.ini` y menú de bandeja)

`hidden`, `monitor` (`primary`/`active`), `hotkey`, `notify_track`, `notify_volume`,
`notify_brightness`, `notify_audio`, `notify_battery`, `notify_privacy`, `focus_min`, `break_min`.
Todos activados por defecto salvo `hidden=0` y `monitor=primary`.
